# LogiTalk💬 
Chat Client (CustomTkinter & Sockets)

Сучасний настільний клієнт для мережевого чату з графічним інтерфейсом, розроблений на мові Python за допомогою бібліотек CustomTkinter та Pillow. Програма підтримує текстове спілкування в реальному часі, передачу зображень у форматі Base64, анімоване меню налаштувань та адаптивний інтерфейс.

🌟 Основні можливості

Обмін текстовими повідомленнями: Швидка передача повідомлень через TCP-сокєти у фоновому потоці.

Передача зображень: Можливість надсилати фотографії та картинки. Зображення автоматично кодуються в Base64 і відображаються прямо в стрічці чату.

Анімоване бічне меню: Виїзна панель налаштувань з плавною анімацією для зміни імені користувача (нікнейму).

Адаптивний UI (Responsive Design): Інтерфейс та блоки повідомлень динамічно підлаштовуються під розмір вікна додатка.

Багатопотоковість (threading): Прийом повідомлень виконується в окремому потоці, що забезпечує плавний і чуйний інтерфейс без заморожування GUI.

🛠 Технології та залежності

Мова програмування: Python 3.8+

Графічний інтерфейс: CustomTkinter (сучасна обгортка для Tkinter)

Обробка зображень: Pillow (PIL)

Мережева взаємодія: socket, threading

Кодування даних: base64, io

📦 Встановлення

Клонуйте репозиторій або завантажте сирцевий код:

git clone https://github.com/your-username/chat-client.git
cd chat-client


Встановіть необхідні бібліотеки:

pip install customtkinter pillow


🔌 Налаштування підключення

За замовчуванням клієнт підключається до віддаленого сервера (наприклад, через тунель ngrok):

self.sock.connect(('7.tcp.eu.ngrok.io', 10858))


Якщо ви запустили власний локальний сервер або змінили адресу, відкрийте код та змініть хост і порт на ваші значення (наприклад, для локального тестування):

self.sock.connect(('127.0.0.1', 8080))


📡 Опис протоколу передачі даних

Клієнт використовує текстовий протокол на основі роздільника @ та символу переведення рядка \n для форматування пакетів:

Текстове повідомлення / Системне підключення:

TEXT@<username>@<message_text>\n


Приклад: TEXT@Max@Привіт усім!\n

Надсилання зображення:

IMAGE@<username>@<filename>@<base64_string>\n


Приклад: IMAGE@Max@photo.png@iVBORw0KGgoAAAANSUhEUgAA...\n

🚀 Запуск додатка

Переконайтеся, що ваш сервер чату запущений, після чого виконайте команду:

python main.py


🖼 Вигляд інтерфейсу та управління

Текстове поле (Внизу): Введіть текст та натисніть кнопку > або Enter для надсилання.

Кнопка 📂: Відкриває системний діалог вибору файлу для відправки зображення.

Кнопка ▶️ (Зліва вгорі): Відкриває анімовану панель налаштувань, де можна змінити свій нікнейм.
